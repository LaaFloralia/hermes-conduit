# LAA iPhoneアプリ：デザイン基盤

2026-10-29。LAA版（master）の見た目と操作の基準。実装順は [ROADMAP](ROADMAP.md)。ここに書く画面は設計で、実機での稼働を示さない。採否は社長が実物で決める。

## 参考と採る点

| 参考 | 観察した点 | 採る点 | 採らない点 |
|---|---|---|---|
| [Apple HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials)・[Adopting Liquid Glass](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass)（主） | Glassは最上位のナビゲーション層。本文層には使わない。regularは文字の多い部品、clearは写真・映像の上だけで、明るい下地には35%の減光層 | Glassの使用箇所と減光、透明度を下げる設定での代替 | 独自部品へのGlassの多用、ナビゲーション部品への独自背景 |
| [Apple HIG App icons](https://developer.apple.com/design/human-interface-guidelines/app-icons) | 1024の背景層と前景層、6つの外観（標準・ダーク・クリア明暗・ティント明暗）、文字を入れない、角丸を描き込まない | 主印を3層に分けた `.icon` | 影・光沢の描き込み |
| [Recent — App Icons](https://recent.design/app-icons) | 強いアイコンは単色の地に主役が1つ、面積の6割前後 | 青緑の地に円弧の主印だけ | 立体の物体・場面を描く作例 |

社員像の画風は、Studio「LAA — CSO / Forest Atelier & Slack Portraits」の7人の肖像に合わせた（社内の採用素材）。Dots（OpenAI）の社員ごとの3Dキャラクターと通話は社長の要件として扱い、画面の実物比較は未了。

## トークン

ブランドはStudio「LAA — Company Brand / 2026.10」v6。ダークの値はこの文書で決めた（コントラストは計算値）。

| 用途 | ライト | ダーク |
|---|---|---|
| 地（紙） | Ivory `#F6F2E9` | `#0F1B1C` |
| 面（入力欄・回答） | `#FFFDF8` | `#172627` |
| 本文 | Ink `#213536`（11.6:1） | `#ECE7DC`（14.3:1） |
| 補助文字 | Muted `#596968`（5.2:1） | `#9AA9A7`（7.2:1） |
| 選択・主操作 | Teal `#00585E`（7.4:1） | `#6FBFC2`（8.3:1） |
| 自分の吹き出し | 地 Teal・文字 Ivory（7.4:1） | 地 `#1E6B70`・文字 Ivory（5.5:1） |
| 要確認 | Plum `#6C244C`（文字・▲・細罫だけ） | `#D49AB6` |
| 罫線・装飾 | Tan `#B99B7A`、Ink 12% | Tan、Ivory 12% |
| 通話終了 | システムの赤（色だけに頼らずアイコンと語を添える） | 同左 |

- 状態は形で示す。●正常、▲要確認、○未確認・古い値。色は補助。
- 余白は4の倍数（4・8・12・16・24・32）。区切りは罫線と余白で示し、角丸カードの入れ子・グラデーション・装飾の影を使わない。
- 角の形は標準部品に任せる。独自の面はGlassの部品と同心の角丸にする。
- 既存の `ConduitAccentChoice` にLAAの青緑を既定として加え、他の色の選択肢は残す。

## Liquid Glass

| 使う（操作層） | 使わない（本文層、落ち着いた面） |
|---|---|
| 下部タブ、チャット上部の戻る・社員名・電話、通話の操作列、必要時に出る編集ツールバー、＋・送信などの丸ボタン | 会話の本文と吹き出し、入力欄の面、Brainの本文、仕事の詳細、Usageの数値、ウィジェットの本文 |

- 標準部品（`TabView`・`toolbar`）の既定のGlassを使い、独自の背景を足さない。独自部品は `glassEffect` を `GlassEffectContainer` にまとめ、使用は上表に限る。
- regularが既定。写真の背景・通話画面の上だけclearを使い、下地が明るければ35%の減光層を敷く。
- 「透明度を下げる」がオンなら面は不透明（ライト `#FFFDF8`、ダーク `#172627`）、「コントラストを上げる」では罫線をInk 40%にする。

## 文字と大きさ

- 本文・操作はシステム書体（SF Pro＋ヒラギノ角ゴ）。Dynamic Typeに追従する。
- 画面の大見出しと社員名はGeorgia Regular（会社規定のロゴ書体）。Usageの数値はIowan Old Styleで、桁を揃える（`monospacedDigit`）。等幅はコードと識別子だけ。
- 表示語は短い日本語。ナビとタブは「会話／仕事／Brain／素材／Usage」。
- 文字の大きさは既存の `ChatTextSize`（5段階、0.85〜1.25倍。システムの文字サイズに掛ける）を使い、設定を「回答の文字」と「入力の文字」の2つに分ける。入力の既定は1段大きい1.125倍。
- 入力欄は3行の高さから始め、8行まで広がり、その先は欄内でスクロールする。右上の⤢で既存の全画面エディター（`ComposerFullEditor`）を開く。下書きの永続化はROADMAPの08。
- 日本語変換中は入力欄を作り直さない（既存のIME保護を維持）。

## 動き

| 対象 | 値 |
|---|---|
| 画面遷移・シート | システム既定 |
| 送信・通話開始などの状態変化 | spring（response 0.35、dampingFraction 0.85） |
| 社員像の待機ループ | 2.0秒・30fps、呼吸1回・首の小さな揺れ・瞬き1回（約120ms） |
| 通話の音量リング | 音量で1.00〜1.08倍、120msで平滑化 |
| ウィジェット | 動かさない（静止画） |

- 社員像は「待機・聞く・考える・話す」の処理状態を示す。表情で感情を断定しない。今回の試作は待機だけ。
- 「視差効果を減らす」、低電力モード、画面外では、ループを止めて1コマ目の静止画にする。

## 5つのタブ

下部タブは最上位の画面だけに出し、個別チャット・通話・文書では隠す。スクロールで縮める（`tabBarMinimizeBehavior(.onScrollDown)`）。

| タブ | 内容 | 上部 | 空・失敗 |
|---|---|---|---|
| 会話 | Cielを先頭に社員一覧、グループ、最近の会話。一覧の社員像は静止画 | 大見出し「会話」、検索、新規グループ | 未接続はHermesの接続先と最終接続時刻 |
| 仕事 | セッション／Project／タスク／ルーティンの切替。人の担当と実行する社員を分けて表示 | 切替（segmented）、新規 | 0件は理由と作り方を1行 |
| Brain | 最近・フォルダ・タグ・検索、本文は紙色の面に組む | 検索、表示切替 | 同期の競合は▲と両版への導線 |
| 素材 | Drive／Inspiration／Studioの切替、正方形の一覧 | 切替、種類の絞込み | 再生できない形式は理由を表示 |
| Usage | 利用枠・実利用・費用・Macの状態 | 更新時刻 | 未取得は○と「未取得」。0で埋めない |

## 社員チャット

- 上部はGlassの3つの部品。左に戻る、中央に社員像（36〜40pt、円形）＋社員名＋状態（●待機中など）、右上に電話。電話はその社員とその会話の文脈で通話を始める。
- 社員像は、その会話を開いている間だけ待機ループを再生する（HEVCアルファ付き、`AVPlayerLooper`）。タップで社員の詳細。
- 本文の吹き出しは不透明。自分は青緑、社員は面の色。下部はGlassの＋、入力欄（不透明）、送信。

## 通話

- アプリ内の通話画面：地は青緑から墨の縦グラデーション、または会話の背景を暗くぼかしたもの。中央上に社員像（直径270pt、待機ループ）と音量リング、Georgiaの社員名、状態と経過時間。下部にclearのGlassで消音・スピーカー・チャット・終了。チャットで元の会話へ戻る。
- CallKit（純正の着信・ロック画面）：任意の3Dや動画は置けない。`iconTemplateImageData` に `assets/callkit-icon-template-120.png`（LAA主印の単色マスク、40pt@3x、中心の螺旋は抜き）を使い、表示名はLAA、発信者名は社員名にする。社員の写真は、端末の連絡先に登録がある時だけ純正画面に出る（連絡先の作成は権限と社長の判断が必要）。
- CallKitのSwiftは別workerの担当。このファイルは画像と表示の仕様だけを決める。

## ウィジェット

既存の `systemMedium` ランチャーを基に、社員を選べる構成にする。初期値はCiel。

| サイズ | 構成 | タップ |
|---|---|---|
| systemSmall | 社員の静止画（`ciel-hero-1024.png` を縮小）、Georgiaの名前、右下に電話の丸 | 全体で会話、電話の丸で通話 |
| systemMedium | 左に顔の静止画（`ciel-avatar-512.png`）、右に名前・役割と「電話」「チャット」 | 各ボタンで通話・会話 |
| accessoryCircular（ロック画面） | 単色の社員シルエットかLAA主印 | 通話 |

- 画像は用途の寸法へ縮小して同梱し、拡張のメモリ上限に収める。ホーム画面のティント・クリアでは画像を `widgetAccentedRenderingMode` で単色にし、文字を読める状態に保つ。
- 状態を出すなら最終確認時刻を添え、更新されていない値を最新に見せない。

## 会話の背景

- 会話・グループごとに背景を保存する。既定は紙（Ivory）。用意する背景は紙、青緑の夜、墨、端末の写真。
- 写真には明るさ（減光0〜60%）とぼかし（0〜20pt）を付ける。背景の明るさを測り、本文が4.5:1を下回る時は減光を自動で足す。
- 吹き出しは常に不透明で、背景に関係なく読めることを優先する。上部と入力の操作部品は、写真の上ではclearのGlassにして減光層を敷く。

## アプリアイコン

- 原本はStudioブランドの「配信用 — PWA 1024 / any」。形・間隔・色を変えずに使う。
- `Conduit/Resources/AppIcon-LAA.icon`（Icon Composer形式、iOS 26以降）：地は青緑、ダークは墨の縦グラデーション。前景は上から「螺旋（プラム）」「四分円（タン）」「円弧（アイボリー）」の3層。ティント・クリアはシステムが作る。
- `Conduit/Resources/Assets.xcassets/AppIcon-LAA.appiconset`：iOS 26未満の代替（1024のライト・ダーク・ティント）。
- 有効にするには、LAA用の署名overlayでConduitターゲットに `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon-LAA` を指定する。上流の `AppIcon` と、別アイコンの選択（`AppIconChoice`）は変えない。
- 検証：`ictool` で6外観を書き出し、`actool` で両方がエラーなくコンパイルされた。ホーム画面での見え方は実機で確かめる。

## 社員像の素材（Ciel）

`docs/laa/assets/ciel/` に置く。アプリへの同梱は実装時に行う。

| ファイル | 用途 |
|---|---|
| `ciel-hero-1024.png` | 透過の静止画。ウィジェット、連絡先の写真、通話の待機前 |
| `ciel-avatar-512.png` | ループの1コマ目。一覧、ウィジェットmedium、動きを止める時 |
| `ciel-idle-512.mov` | 2.0秒の待機ループ。HEVCアルファ付き（hvc1、512²、30fps） |

画風は2.5D（3D調の肖像を変形した動き）で、RealityKitの3Dモデルではない。本物の3D（顔の向き・口の動き）は手順8で判断する。

## 社員3Dの制作手順（残り7人）

1. 原本：Studio「LAA — AI社員アイコン / 2026.10」の平面アイコン（特徴）と、7人の肖像（人物）。
2. 生成：Codex内蔵 image_gen（ChatGPTサブスク）。Image 1を本人の肖像、Image 2を平面アイコンにし、「同じ人物・髪・服のまま、胸から上・正面・中央、頭頂は上端から8%、無地の `#E6E2DA` の背景、1:1」で作る。Cielの指示文は `assets/ciel/prompt-hero.txt` と `prompt-blink.txt`。
3. 瞬き：同じ画像を編集し「目だけ閉じる、他は変えない」。目の周り以外の差が小さいことを確かめる。
4. 切抜き：Studioの `studio_image_cutout`（ローカルBiRefNet）か、同等の人物用モデル。髪の縁を青緑・墨・写真の上で確認する。
5. 動き：`scripts/laa/staff_avatar.py`（Pillow・numpyが必要）に目の中心・首の付け根・顎の線・切出し範囲を渡す。Cielの値は `--eyes 537,490,745,490 --pivot 627,800 --chin 860 --crop 252,66,750`（1254²の原画）。
6. 書出し：`ffmpeg -framerate 30 -i loop/idle-%03d.png -c:v hevc_videotoolbox -alpha_quality 0.9 -q:v 70 -tag:v hvc1 -pix_fmt bgra <name>-idle-512.mov`。AVFoundationでアルファ付きか確かめる。
7. 確認：44ptと270pt、紙・青緑・墨・写真の背景で見る。瞬きの残像、ループのつなぎ目、首と髪のゆがみ、1コマ目の静止画を確認する。
8. 本物の3D：Studioのローカル3D（Pixal3D）はCSOの試作で顔が崩れ、10月12日に重みの不一致で停止した。RealityKitで動かすには、頭のボーンと瞬き・口のブレンドシェイプを持つモデルが必要。外注かBlenderでの制作かは社長の判断とする。
