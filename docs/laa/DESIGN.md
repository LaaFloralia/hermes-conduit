## 共通トークン

Studioブランド「LAA — Company Brand / 2026.10」v6を基準にする。ダークと補助面は今回の画面用の値。カラーは用途名で参照し、画面ごとに直接固定しない。

| 用途 | Light | Dark |
|---|---|---|
| 背景 | `#F6F2E9` | `#0F1B1C` |
| 本文・カード面 | `#FFFDF8` | `#172627` |
| 補助面・コード | `#EBE6DC` | `#243638` |
| 本文文字 | `#213536` | `#ECE7DC` |
| 補助文字 | `#596968` | `#A8B7B4` |
| リンク・選択文字 | `#00585E` | `#75C3C3` |
| 罫線 | `#D7D5CC` | `#385052` |
| 選択アイコンの下地 | `#DFEAE5` | `#294844` |
| 自分の吹き出し・塗りボタン | `#00585E` / 文字 `#F6F2E9` | `#1E6B70` / 文字 `#F6F2E9` |
| 要確認 | Plum `#6C244C` | `#D49AB6` |
| 終了 | システムの赤 | システムの赤 |

通常文字は下地とのコントラスト4.5:1以上。例として本文／背景はLight 11.55:1、Dark 14.27:1、塗りボタンはLight 7.35:1、Dark 5.54:1。Plum・Tan `#B99B7A` は装飾にも使うが、通常文字に使う場合は実際の下地との比を確認する。色だけで状態を伝えず、文言・記号を添える。

- 余白の基本は4・8・12・16・24・32pt。390pt幅の見本は左右24pt、セクション間32pt。小さい画面では左右16ptまで縮める。
- 標準行の高さは56pt以上。カードは角丸16pt、吹き出し18pt、選択チップ16pt、写真24pt、操作面の大きな角は28ptを基準とする。入れ子のカードを増やさず、余白と細罫で区切る。
- 本文・操作はシステム書体（SF Pro／日本語はシステムの日本語書体）、通常本文16pt、補助13pt、セクション名12pt。画面見出しはGeorgia Regular 34pt、社員名はGeorgia、Usageの数値はGeorgia 36pt・等幅数字。Dynamic Typeでは折り返しと行高を広げ、固定高で切らない。Studio上のHelvetica Neueはシステム書体の見本。
- タップ領域は44×44pt以上。小さく見えるアイコンやチップも透明な当たり領域を広げる。VoiceOverに名前・選択状態を渡す。色覚・文字サイズ・Reduce Motion・Reduce Transparencyを実機で確認する。
- 回答と入力は既存の `ChatTextSize` を維持し、システムの文字サイズに追従する。回答と入力の設定は分け、入力の既定は1.125倍。

## Glassと画面構造

| 操作層：Glassの対象 | 本文層：不透明に保つ |
|---|---|
| タブバー、チャットの戻る・社員情報・電話、通話操作、編集ツールバー、チャットの入力欄（＋・入力面・送信） | チャットの吹き出し、Brain本文、仕事詳細、Usageの数値、ウィジェット本文 |

iOS 26以降は標準 `TabView`・`toolbar` のシステム表現を優先する。Chats・Today・Doc・Studioの見出しは共通（LAAの上にGeorgiaの画面名）とし、ナビゲーションバーのボタンはシステムのガラスにまとめる。検索欄・絞り込みチップ・操作ボタンは標準のガラス（`LAAGlass.swift`）、一覧の行・カード・本文は不透明に保つ。独自操作に必要な場合だけ `glassEffect` を `GlassEffectContainer` でまとめる。regularを既定とし、clearは写真・映像の上に限る。明るい写真上のclearには最低35%の暗い下地を敷く。透明度を下げる設定ではLight `#FFFDF8`／Dark `#172627` の不透明面にする。コントラストを上げる設定では文字・境界を強める。

対象はiOS 17以降。iOS 17–25は標準のナビゲーションと `Material` を使い、不透明設定では同じ代替面にする。iOS 26専用APIとスクロール時のタブ縮小はavailabilityで分岐する。静止画の半透明色をLiquid Glassの実装と見なさない。

下部タブは最上位だけに出し、個別チャット・通話・文書では隠す。Safe Area・キーボード・横幅に追従し、本文を操作面の下に隠さない。画面の描画値は390×844ptの見本であり、座標を全端末に固定しない。

| 順序 | 表示名 | 主な内容 | アイコン |
|---|---|---|---|
| 1 | Chats | Monet、社員、グループ、最近 | `bubble.left.and.bubble.right` |
| 2 | Work | Sessions、Projects、Tasks、Routines | `checklist` |
| 3 | Doc | Recent、Folders、Tags、検索 | `doc.text` |
| 4 | Assets | Drive、Inspiration、Studio | `photo.on.rectangle` |
| 5 | Usage | サービスごとのAI利用枠・残高 | `gauge.medium` |

ナビゲーションと操作ラベルは英語。会話本文や日本語の説明は自然な日本語でよい。内部の `source` など既存識別子・保存済みリンクは表示名の変更だけで壊さない。

## Chats：相手を選ぶ一覧

画面上部に `Chats`、検索、新規作成。縦スクロールの順は `Monet`、`Employees`、`Groups`。Monetは最初に大きめの1行で固定し、Employeesは既存の社員データ、Groupsは参加中のグループを、折りたたまずに全件表示する（Recentは2026-11-02に社長の指示で削除。会話の一覧はWorkのSessions）。`+` は既存の作成フローへ進む。未実装の作成操作を成功したように見せない。

社員行は40〜44ptの静止アバター、表示名、役割を並べる。グループ行は参加社員の顔を同じ大きさの枠に重ねて示す（2人は斜め、3人以上は3つの塊、4人以上は3つ目を人数）。実際に取得できない状態や未読数は作らない。検索は相手名・役割・グループ名・メンバーを対象にし、結果なし、読み込み中、接続失敗を区別する。

## Chat：社員・グループとの会話

上部に戻る、40ptの社員像、名前、取得できる場合のみ状態、電話ボタン。社員名のピルは画面の水平中央、電話と `…` はシステムのツールバー項目として1つのガラスにまとめ、戻るボタンと同じ端の余白を取る。入力はプレーンテキストで、書式ツールバーとプレビューは置かない（2026-11-02、社長の指示）。入力欄にフォーカスしたら最新の発言へスクロールし、送信ボタンは＋と同じLiquid Glassにする。電話はその社員と現在の会話文脈を渡す。グループでは実際に対応する通話先がない限り電話を無効にして理由を示す。一覧から選んだ会話IDを保ち、履歴や下書きを混ぜない。

本文は縦スクロールで、相手の吹き出しは左、自分は右。最大幅は画面の85%、内側16pt、角丸18pt。どちらも不透明にし、長文は自然に高さを伸ばす。到着時刻・送信中・失敗・再送は実データに従い、色以外でも区別する。ユーザーが過去を読んでいる間の自動スクロールを避け、末尾へ戻る導線を出す。

リッチ表示は既存Markdown／添付コンポーネントを再利用し、次を少なくとも表現する。

| 種別 | 表示と操作 |
|---|---|
| 見出し・段落・太字 | 行間を確保し、選択・コピーできる |
| 箇条書き・番号付き | 段落内でインデントし、折り返しても番号を読める |
| 引用 | 補助面と左の細線で本文と区別 |
| コード | 等幅、補助面、横スクロール、`Copy` |
| リンク | 青緑とリンク記号、VoiceOver名。外部遷移はOSの通常の開き方 |
| 画像 | 会話内サムネイルから拡大。読み込み・失敗・代替テキストを用意 |
| ファイル | 種別、名前、取得可能ならサイズと開く操作。未対応形式は理由を示す |

未対応の書式や添付を黙って捨てず、取得できる原文・ファイルへの導線を表示する。画像やファイルの例はサンプルで、送受信機能の完成を示さない。

下部は＋、入力面、送信。iOS 26純正メッセージと同じく、3つとも標準のLiquid Glass（regular）にする（2026-11-02、社長の決定）。＋と送信は直径44ptの円、入力面は角丸22pt（1行ならカプセル）で、1つの `GlassEffectContainer` に入れ、並んでも溶け合わせない。送信は送れる時だけ自分の吹き出し色で色付けする。入力面は下を流れる会話が透けて読めないようclearにせず、写真背景では38%の暗い下地と明るい文字にする（白い写真でも本文4.5:1以上を試験で確認）。透明度を下げる設定とiOS 17–25は不透明な面（Light `#FFFDF8`／Dark `#172627`）と細罫、コントラストを上げる設定では境界線を加える。実装は `LAAChatStyle.swift` の `laaComposerGlass`。入力欄は3行から8行まで伸び、それ以上は欄内スクロール。全画面エディターへの導線を残し、日本語変換中に入力欄を再生成しない。送信可否、添付、下書き、キーボード位置は既存の動作を保つ。純正と違い、送信は入力面の外の右に置く。

## Call：アプリ内通話

`Chat` の電話とウィジェットの `Call` は、選んだ社員と会話を引き継ぐ。中央に直径270ptを上限とする社員マスコット、社員名、実際の状態と通話時間。下に `Mute`、`Speaker`、`Chat`、`End` の順で配置する。`Chat` は通話を切らず元の会話を開き、`End` は終了する。

接続中・接続済み・再接続・失敗・終了、マイク許可、音声経路を区別する。GPT-Liveを使う設計だが、社員別の声は利用可能な選択肢と既存接続方式を実装時に確認し、未対応なら共通の利用可能な声とする。画面の `GPT Live` は表示例。既存の送信先同意、ChatGPTプラン／APIの課金表示、利用経路の確認を省かない。

CallKitの純正画面には任意の3D・動画を置けない。アプリ内の社員像とは分け、`assets/callkit-icon-template-120.png` を単色マスクとして使う。表示名はLAA、発信者名は社員名。純正画面で連絡先の写真を使うには端末側の条件と社長の判断が必要。

### Work：判断ボード（2026-11-08）

エージェントが社長の判断を待つ項目を、Workの最初のセクション「判断」（英語 `Decisions`）に集める。pillに件数を出し、項目がある時だけWorkを「判断」で開く。HTTPと記録はBridgeの [BRIDGE](BRIDGE.md) と `bridge/README.md`。

| 部分 | 構成 | 採らないもの |
|---|---|---|
| 一覧 | 1行1件。題（何を決めるか）を主役にし、下に控えめな1行で依頼元（`S5 · 会話名`、番号がなければ会話名だけ）・期限（相対表記、24時間以内はPlumの太字）・`推奨 <選択肢>`。左に選択アイコンの下地色の丸い印（板は `?`、会話の質問は吹き出し、未着は再送）。未着の行は「届いていません」と理由、`届け直す` | 説明文・選択肢の一覧を行に並べること、色だけの状態表示 |
| 詳細（シート） | 依頼元、題（title2）、短い説明、影響と期限の小さな事実、全幅の選択肢カード（推奨を先頭に「推奨」タグ）、「その他（自由記入）」。下端に1つだけの塗りボタン `この内容で送る`。選択で選択アイコンの下地色・青緑の細枠・チェック、selectionのhaptic | 確認ダイアログの二重確認、選択肢ごとの大きさの差（HIG：推奨は大きさでなく表示で区別） |
| 届いた時 | 送信中はボタン内に進捗（ボタンの大きさは保つ）。届いたら青緑のチェックが弾み（Reduce Motionではフェードだけ）、成功のhaptic、「届けました」1行の後にシートが閉じ、行が一覧から抜ける。依頼元の会話がない時は「記録しました」 | 紙吹雪・発光・原本にない影・全画面の演出 |
| 届かない時 | 回答は保存済み。詳細に「届いていません」、理由、保存した回答、`もう一度届ける`。行は一覧に残る | 失敗を成功のように閉じること |
| 会話の質問 | 同じ見出しの下に既存の回答画面（`LAAWorkSessionDecision`）をそのまま置き、返信の処理を複製しない | 2つ目の返信経路 |
| 空・古いMac・接続失敗 | 「判断待ちはありません」（チェック）、404は「Macのアップデート待ち」、読めない時は理由と `読み直す`。未接続はWork共通の接続案内 | 空を失敗に見せること |

色・角丸・余白は既存トークンだけを使い、新しい色・枠は足さない。VoiceOverは行を「判断、<題>、推奨 <選択肢>」から読む。参考：HIG Lists and tables（行は短く、詳細は別画面）、Buttons（目立つボタンは1画面1〜2個、推奨は大きさでなくスタイルで区別、押下状態を必ず持つ）、Feedback（重要な操作だけ完了を確認し、失敗は理由を示す）、60fps.designのRevolut「Create Close Pocket」（ボタン内の進捗から結果へ短くつなぐ。粒子で消える演出は採らない）。

## Usage

上部に `Usage`、更新ボタン、最終取得時刻。並びは Codex Weekly、OpenCode Weekly、Claude Weekly、nanoGPT、Venice、GPT API、Claude API、Liquid AI。7日の枠は「Weekly」（日本語は「ウィークリー」）に統一し、`D1` とは書かない。Jev・Google Cloud・Google Flow は出さない。サービスごとに、取得可能な利用枠・残高・クレジット・リセット時刻を単位付きで表示する。proxyが提供するD1の記録済み費用・入出力トークン・応答数も表示し、モデル名は表示しない。2026-10-31の社長指摘に従い、Hermesのモデル・トークン情報やMac状態はこのタブに置かない。比率は分母が明確なサービスだけに表示し、異なるサービスの利用率を合算しない。見本の62%、時刻、サービス状態は仮値。

更新中はボタンを重複実行できない状態にし、取得完了時刻を表示する。失敗時は前回取得値とその時刻を残してエラーを添える。未取得・利用不可・0・古い値を区別し、未取得を0で埋めない。時刻は端末のロケールとタイムゾーンで表示する。

## Widgetとロック画面

ホームは `systemSmall` の正方形。Monetを初期値とし、上段に名前・静止3D、下段に `Call` と `Chat` の2操作を並べる。見本は170×170pt、各ボタンの当たり領域は44pt以上。実寸はWidgetKitが決めるため、縮小時は画像と余白を調整し、文字と2操作を残す。ウィジェット全体の既定遷移はChat、Callは対象社員の通話、Chatはその社員の会話。iOS 17以降の `Link` と1つの `widgetURL` で行き先を区別する（[Appleの遷移仕様](https://developer.apple.com/documentation/widgetkit/linking-to-specific-app-scenes-from-your-widget-or-live-activity)）。ロック解除・権限・既存の通話同意が必要な場合はアプリ側で正規の流れを示す。

横長 `systemMedium` は、左上に会社（LAA）のアイコンとMonetの名前、その下にMonet像と電話・会話のアイコン操作（アイコンだけを置き、下地や光彩を付けない）、右にAI Usageを優先順（Codex Weekly、OpenCode Weekly、Claude Weekly、Venice、GPT API、Claude API、Liquid AI）で上から入る分だけ置く。アイコンにはVoiceOver名を付ける。右側のタップはUsageタブを開き、外部URLは開かない。取得時刻などの脚注は置かず、取れない項目は数値なしの状態行にする。

ロック画面は `accessoryRectangular`、単色の電話アイコンと `Monet / Call`。1つの遷移先としてアプリの通話画面を開く。実際の色や形はOSのレンダリングに従うため、Studioの色付き見本と完全一致を要求しない。ロック画面に会話内容や接続状況を表示しない。

ウィジェットは静止画。ティント等の外観ではOSが画像を処理するため、文字・操作の視認性を実機で確認する。状態を表示する場合は最終確認時刻も表示し、古い値を最新に見せない。

## Mac

2026-11-03。Mac版は同じLAA版をMac Catalystで作り、iPhoneの画面を拡大せずに、横長のウインドウへ組み直す。iPhone 440×956の外観と挙動は変えない。数値はMac pt。

- 尺度: Catalystの「Scale Interface to Match iPad」を維持する（UIKit pt×約0.77がMac pt）。ウインドウ既定1280×820、最小900×600。上限は表示器に任せ、全画面・分割表示・ドラッグ拡大を許す。623ptの本文幅上限と、ルートでのcompact強制は置かない。
- 外枠: `NavigationSplitView`。サイドバーは Georgia の `LAA` 見出しと `AIアプリ`、`SECTIONS` の下に Chat・Work・Today・Brain・Studio・Drive・Usage。下部に接続状態（点＋文言）と Settings。選択は `LAAColor.selectionFill` の地に `LAAColor.link` の文字とアイコン（システムのアクセント塗りは使わない）。ライト #DFEAE5／#00585E は 6.6:1、ダーク #294844／#75C3C3 は 4.9:1。ホバーは `LAAColor.subtleSurface`。
- 詳細列: 各セクションが自分で「一覧｜詳細」を組む。一覧の幅は `LAADesktopMetrics`（最小320・既定380・最大460 UIKit pt）。カード一覧は `LazyVGrid` の adaptive（最小300）で列を増やす。本文・会話・入力欄は `laaReadableWidth`（会話880、文書820）で中央に寄せ、行長を伸ばさない。
- 操作: 一覧はクリックで右が切り替わる（pushしない）。選択行は常時強調、ホバーで淡い下地、右クリックは既存操作がある行だけ、ツールチップは `.help`。↑↓で行移動、Returnで開く、Escで会話を閉じる、⌘F検索、⌘R再読込、⌘N新規、⌘1〜⌘7セクション、⌃⌘Sサイドバー、⌘,設定。ボタンと行の当たり領域は44pt以上を保つ。
- 状態: 通常・空・読込中・エラー・オフライン・未ペアリングを詳細列でも破綻させない。未ペアリングとログインは Chat セクションに出す（iPhoneのChatsタブと同じ位置）。他のセクションはそれぞれの未接続表示を保つ。
- 本文と操作層の分離、紙色・細罫・青緑の選択、Georgiaの見出しはiPhoneと同じトークンを使う。ライト・ダークの両方を撮って確かめる。

## 会話の背景と動き

会話・グループごとに背景を保存する。既定は紙（Ivory）、選択肢は紙・青緑の夜・墨・端末の写真。写真の減光は0〜60%、ぼかしは0〜20pt。写真上の操作層には上記のGlass規則を適用する。文字が4.5:1を満たせないときは暗い下地を追加し、それでも足りなければ不透明な操作面に戻す。吹き出し自体は背景に関係なく常に不透明。

画面遷移・シートはシステム既定。送信・通話開始の状態変化はspring（response 0.35、dampingFraction 0.85）を基準とする。社員マスコットのループは約4秒・24fpsで、チャット上部と通話で再生する。チャットの応答中と通話で話している間は1.4倍速にする。音量リングは1.00〜1.08倍、120msで平滑化する。通話の像は同じ音量で下端を支点に最大5%つぶれる。Reduce Motion、低電力モード、画面外ではループを止め、1コマ目に戻す。表情で感情を断定しない。

## 社員マスコットの制作手順

### 待機ループ

動画は透過なので、1コマ目が表示されたら下の静止画を隠す（残すと2体が重なる）。採用した静止画を動画生成で動かし、背景を抜いて使う。

1. Studioの `studio_image_cutout` で採用画を切り抜く。外周幅の対角が760pxになるよう拡大し、1280×720の単色地の中央へ置いて開始フレームにする。地は像にない色にする（既定は緑、Adaはマゼンタ、Morganは空色）。
2. Flow（Omni 1.1 Flash、720p・4秒）で、同じ画像を開始と終了に入れて生成する。依頼文は固定カメラ・主な動き一つ・最初の姿勢へ戻る・地は平らで影なし、を書く。Flowの枠が尽きた時はMagnificのKling 2.6へ回す。Veo 3.1 Liteは漫画の線が出たため使わない。Klingは開始と終了が同じだと動きが小さくなることがある。その場合は終了画像を外し、前半を順再生と逆再生でつなぐ。5秒の素材は4秒へ縮める。
3. `python3 scripts/laa/staff_3d/matte_loop.py <作業フォルダ> <id> <動画>` で、色抜き、輪郭を2px削って地の色を除去、466pxへ縮小して512の中央へ置く（動いても円で切れない）、影の追加、末尾10コマを1コマ目へ寄せる、HEVCアルファの書出し、静止画の書出しを行う。HEVCアルファは色をアルファで乗算してから書き出す（`premultiply`）。AVFoundationは必ず乗算済みとして重ねるので、乗算しないと明るい地で輪郭に白い縁が出る（社長の指摘した「白い囲み」の正体。`testEveryLoopIsPremultiplied` で防ぐ）。
4. アルファは `swift scripts/laa/staff_3d/verify_alpha.swift <mov>` で確かめる。全コマの輪郭を重ねて円の外に出ないこと、継ぎ目、38pt・44pt・270ptを明暗の地で見る。暗い色の派生（例：Monet（無検閲））は、38ptの暗い地で輪郭と顔が読めるまで暗部を持ち上げる（2026-11-08、茄子紺へ補正して採用）。
5. 元の動画はStudio作品「LAAアプリ｜社員マスコット」（`cf51462f-250f-413b-9f6e-b41540841fec`）に入れる。

### 360度の回転

採用画の質をそのまま回すため、事前に作ったコマを指で送る。リアルタイムの3Dモデルは採らない。SDFとシェルの毛は「ふわふわしない、目が飛び出る」と社長が却下し、MagnificのTripo H3.1は形は正しいが質感が粘土になり、Cycles（Blender）で毛を生やすと別の生き物になった。縦方向には回らない。背面はAIの推定で、モデルの実物ではない。

1. 待機ループと同じ開始フレームをKling 2.6（Magnific、1080p・5秒）の開始と終了に入れ、「見えない回転台で等速に1周、カメラ固定、他は動かない、地は平らで影なし」と頼む（225クレジット）。Flowでは試していない。
2. `python3 scripts/laa/staff_3d/turn_frames.py <作業フォルダ> <id> <動画> 0x<地の色> 0.13` で、1080²へ切り、色を抜き、影を敷き、回転が等間隔になるよう60コマを選び、HEICへ詰める（1体1.4〜2.7MB）。Klingは始めと終わりが遅いので、コマ間の変化量の累計で等分する。
3. 右へなぞると正面が右へ動く向きに揃える。逆回りの動画は `--reverse` を付ける（Merlin、Sherlock、Talos）。緑地の像は `--despill` で地の色の滲みを抑える。Talosは裏の穴に地が残るので `--fill` も付ける。
4. 8方向の並びで、向き・輪郭・飾りの消失を見る。

`StaffMascotView` は、指が触れている間だけ `StaffMascotTurner` がコマを1枚ずつ別スレッドで展開する（速いドラッグではコマを飛ばす。メモリに残るのは1枚）。離すと惰性で回り、1.6秒後に近い方から正面へ戻って待機ループへ替わる。Reduce Motionでは惰性も戻りの回転もなく、すぐ替わる。音を使わないので、iOS 26以下とMacでも回る。
