# 社員への電話

Monetを含む7社員の電話は、LAAの通話画面からGPT-Liveの既存サブスク接続を使う。Monet · Dotsは外部ChatGPTへ渡す別経路で、LAAの人格・文脈・道具は引き継がない。アプリ内通話の既定は通常Monet。

接続前に社員profile・声・サブスク課金を固定し、同じprofileのSOULを取得する。指示の先頭に社員の名前・一人称「私」・呼称「社長」を入れ、接続後の静かな文脈でも短く再提示する。技術を尋ねられた場合は、社員としての名乗りを保ってGPT-Liveを使っていると答える。結果・進捗・入力したチャットの更新にも社員の指示を再提示する。

開いている同じチャットの直近8発言を、社長と社員の両方から最大4,000文字取り込む。道具・思考・システムの行を除き、引用した会話データとして渡す。別チャットの内容は混ぜない。初期の会話履歴がない場合も、以前の返事1件だけに頼らず直近の依頼を理解できる。

サブスク接続の道具呼出しは `delegation.created`。通常のAPI用の関数定義を追加しない。依頼は `VoiceBackgroundJobSupervisor.liveThread` が示す社員の通常会話へ送り、結果は同じ会話に残る。通話中は `delegation.context.append` で返す。日本語で「確認して社長にご報告します」などと言って委任を出さない場合は、4秒待ってから未送信の発言を1回だけ渡す。遅れて出た委任で重複実行しない。実配送前に受付済みと断定しない。

一時的な回線断では「再接続中…」を表示し、結果を待機させる。復旧時に社員の指示を戻してから結果を届ける。6秒以内に戻らない場合は通話を終了する既存の処理へ進む。再接続で別の課金経路へ切り替えない。

通話画面はマスコットと4操作の配置を維持する。状態は「接続中…」「話せます」「聞いています」「考えています」「再接続中…」「切れました」。操作は「消音・スピーカー・チャット・終了」。出力先はVoiceOverで確認でき、消音中は解除操作として読み上げる。失敗の内部メッセージは表に出さず、マイク未許可は設定での許可を案内する。

`LAAEmployeeCallContinuityTests` は、社員指示の500バイト制限、同じチャットの文脈、未委任発話の配送と重複防止、結果待機・復旧、状態文言を確認する。`LAAStaffCallUITests` は通話からチャットへ戻る操作、消音、ライト・ダーク、出力先の画面を確認する。実マイク・日本語音声・CallKitは実機で受け入れる。
